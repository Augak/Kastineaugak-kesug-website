# Kastine Augak — Personal & Professional Website

A lightweight, static Astro website for Kastine Augak. Built for mobile-first use, accessibility, low-bandwidth browsing and search discovery.

## Stack
- Astro static site generation
- Native CSS and minimal browser JavaScript
- No client-side framework or external runtime dependency

## Local development
```sh
npm install
npm run dev
npm run build
npm run preview
```

## Deployment
The `site-refresh` branch builds a GitHub Pages review preview at:
`https://augak.github.io/Kastineaugak-kesug-website/`

The production canonical domain is `https://kastineaugak.kesug.com/`. This repository does not automatically upload to InfinityFree. Production publishing requires a separate, explicit approval.
