# Kastineaugak-kesug-website
Kastine Augak Website

The official personal and professional website of Kastine Augak, covering technology, innovation, digital media, research, publishing, and creative projects.

🌐 Live website: https://kastineaugak.kesug.com/

About

Kastine Augak is a technology enthusiast, innovator, researcher, and digital creator. This website brings together professional information, publications, projects, ideas, and digital content in one accessible platform.

Website goals

- Present Kastine Augak's biography, work, and interests.
- Showcase technology and innovation projects.
- Publish articles, research, and digital media.
- Provide links to social media and other online platforms.
- Make information accessible across mobile phones, tablets, and computers.
- Deliver a fast, responsive, and search-engine-friendly experience.

Main features

- Responsive, mobile-first design.
- Professional biography and portfolio.
- Projects and publications.
- Blog and digital content.
- Social media links and contact information.
- Search-engine optimization (SEO).
- Accessibility and performance improvements.

Hosting

This project is hosted on InfinityFree.

The website's source code is maintained in this GitHub repository. Deployment automation through GitHub Actions and FTP will be configured separately.

Development

The project will prioritize:

- Clean, maintainable code.
- Lightweight pages and optimized assets.
- Compatibility with older Android devices and slower connections.
- Accessibility, including screen-reader support.
- Secure handling of credentials and private configuration.
- Reliable functionality rather than decorative or non-functional features.

Deployment

Deployment will use InfinityFree FTP through GitHub Actions once the hosting connection has been configured.

FTP credentials must be stored securely in GitHub repository secrets. Never commit passwords, API keys, or other private credentials to this repository.
